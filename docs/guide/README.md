# The k-bench guide

For someone setting k-bench up and using it. To change k-bench itself, read [CONTRIBUTING](../../CONTRIBUTING.md) and [the internals](../internals/README.md) instead.

1. [Setup](setup.md): turn on Tailscale's HTTPS certificates, then install, update and uninstall k-bench.
2. [Using k-bench](using-k-bench.md): Workspaces, the Prime and the Worker, Other Sessions, Panes and Tabs, what is kept where, Stopped Sessions, Bells, the History and the Phone layout.
3. [Using k-bench with Claude Code](claude-code.md): how the Prime and Worker fit together, the New Claude dialog, Focus view, resuming on restart, seeing whether a Claude Session is Working, Waiting or Idle, and making Claude Code ring the Bell.
4. [Troubleshooting](troubleshooting.md): start from `k-bench status`, then the common failures and where the logs are.

New here? Follow the [quick start in the README](../../README.md#quick-start), then read "Using k-bench". The words this guide capitalises, such as Workspace, Prime and Device, are defined in [GLOSSARY.md](../../GLOSSARY.md).
